# Edge Vault 部署配置指南

> 部署前需要完成的所有控制台配置都在这一页。代码已就绪，按顺序操作即可。

## 1. 创建 Makers 项目并连接仓库

1. EdgeOne 控制台 → Pages/Makers → **创建项目** → 选择 **从 Git 仓库导入** → 选 `keaidang/edge-vault`
2. 框架预设选 **无框架 / 其他**，构建命令留空，输出目录填 `public`（静态页面全部在 public 下）
3. 部署分支：`main`

> 目录说明：边缘函数在 `edge-functions/`（若你的项目是经典 Pages 模板且要求 `functions/` 目录，把 `edge-functions` 整体重命名为 `functions` 即可，代码不用改）。

## 2. 创建并绑定 KV 命名空间（3 个）

控制台 → **KV 存储** →（如未开通先点申请开通）→ 创建以下 3 个命名空间，然后逐个 **绑定到项目** 并设置变量名（变量名必须完全一致，代码里以全局变量引用）：

| 命名空间名称 | 绑定变量名 | 用途 |
|---|---|---|
| `edge-vault-state` | `state_kv` | 系统状态/密钥材料/哈希/文件元数据/笔记/配额 |
| `edge-vault-session` | `session_kv` | 会话 Token |
| `edge-vault-audit` | `audit_kv` | 链式哈希审计日志 |

绑定路径：KV 存储页 → 命名空间 → 关联项目 → 绑定项目 → 填变量名；或项目详情 → KV 存储 → 绑定命名空间。

## 3. 配置环境变量

项目详情 → **环境变量**，添加以下全部条目：

| 变量名 | 值 | 说明 |
|---|---|---|
| `R2_ACCOUNT_ID` | `72492b22c12ea0ba05a8980001cbf4f0` | Cloudflare 账户 ID |
| `R2_ACCESS_KEY_ID` | `81a2edac0030f87e89ce2939c5fc0a90` | R2 API Token 的访问密钥 ID |
| `R2_SECRET_ACCESS_KEY` | （你的机密访问密钥） | ⚠️ 务必勾选"加密/私密"类型 |
| `R2_BUCKET` | `edge-vault` | 专用桶 |
| `SESSION_SECRET` | （openssl rand -hex 32 生成） | 会话签名 + 审计链哈希密钥 |
| `INTERNAL_TOKEN` | （openssl rand -hex 32 生成） | schedules 调用 /api/internal/* 的鉴权 token |

生成密钥：`openssl rand -hex 32`，两个变量用不同的值。

## 4. R2 桶检查（已完成大半）

- ✅ 桶 `edge-vault` 已建好，Token 权限 Object Read & Write 已实测通过
- 建议关闭桶的公开访问（`vault.keaidang.top` 公开域不用，密文全部走预签名 URL）
- 无需开启版本控制、生命周期规则保持默认（保证删除即干净）

## 5. 定时任务（schedules）

已写入仓库 `edgeone.json`，部署时自动生效，无需控制台操作：

| 任务 | cron | 作用 |
|---|---|---|
| `self-destruct-sweep` | 每 5 分钟 | 签到超时 / 胁迫码触发 → 先删钥后删密文 |
| `audit-archive` | 每天 03:30 | 前一日审计日志归档到 R2 `archive/` |

> 若控制台提示 schedules 需要单独开通/白名单，按"定时清理与归档，每 5 分钟触发一次"申请。

## 6. Blob 说明

原方案的笔记 Blob 存储调整为 **KV 存储**（平台约束：Blob SDK 仅支持 Node 函数，Node 函数无法访问 KV；而新版 KV 单值上限 25MB、单命名空间 1GB，完全容纳笔记密文）。笔记正文/标题在 KV（不占保险库配额），笔记图片附件仍走 R2 预签名（`notes/att/` 前缀）。无需创建任何 Blob store。

## 7. 验证清单（部署后逐项过）

1. 打开站点 → 显示"首次初始化"向导
2. 设置主口令 + 胁迫口令 + 签到超时 → 初始化成功
3. 用主口令解锁 → 进入保险库
4. 上传一个文件 → 列表出现，配额进度条增长
5. 下载该文件 → 内容与原文件一致（客户端解密验证）
6. 存储设置 → 修改配额（如 5GB→1GB）→ 保存成功
7. 新建笔记、保存、关闭、重新打开 → 内容一致
8. KV 控制台检查：`state_kv` 出现 `state:system`、`hash:checkin`、`key:me`；`audit_kv` 出现 `audit:1...`
9. R2 控制台检查：`vault/` 出现密文对象
10. 手动测试自毁：把签到超时改为 1 小时后等待（或直接在设置里点销毁）→ R2 `vault/`、KV `key:me` 全部清空，页面显示"系统已销毁"

## 8. 安全提醒

- `SESSION_SECRET` / `INTERNAL_TOKEN` / R2 密钥只在控制台环境变量中，严禁写入代码仓库
- 胁迫口令登录后系统表面正常，但 ≤5 分钟内 sweep 会自动销毁全部数据
- 60 秒无操作自动登出，私钥只在浏览器内存
